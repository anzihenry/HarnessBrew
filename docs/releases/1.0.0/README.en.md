# 1.0.0 Release Record

[中文主版本](README.md)

1.0 is the breaking unified-state/transaction baseline: public APIs become createHarness and harnessbrew/adapter, old CLI aliases/Receipt/Cellar disappear, and declarations require format/version.

Recorded validation used dirty local development packages, not clean release candidates. Original reports are not archived in the repository. See [refactoring](../../initiatives/refactor/unified-state-transactions/README.en.md) and [content](../../initiatives/feature/content-lifecycle/README.en.md) for sources/limitations. Status remains planned, not published.

Back up old data, select empty Home, convert source/asset/Bundle/plugin declarations, explicitly trust/authorize, preview/apply and run doctor. Old targets are not automatically claimed. Official publication requires a clean same-digest candidate and fresh evidence under [release procedures](../../guides/releasing.en.md).
